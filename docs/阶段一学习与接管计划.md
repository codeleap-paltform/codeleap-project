## 二、现有项目的最小知识地图

### 1. 一次请求是怎样完成的

以“查询任务”为例：

1. 用户打开前端任务页面。
2. Vue Router 根据地址显示任务页面。
3. 任务页面调用封装后的 Axios。
4. 浏览器向后端发送 HTTP 请求，同时携带 Session Cookie。
5. 后端 AuthInterceptor 检查用户是否登录。
6. TaskController 接收请求并取得当前用户 ID。
7. TaskService 调用 MyBatis-Plus。
8. TaskMapper 操作 MySQL 中的 task 表。
9. 后端用统一 Result 格式返回 JSON。
10. Axios 收到响应，Vue 更新 taskList，页面重新渲染。

必须能在代码中找到下面这些文件：

- 前端入口：`frontend/src/main.js`
- 根组件：`frontend/src/App.vue`
- 路由：`frontend/src/router/index.js`
- Axios：`frontend/src/utils/request.js`
- 登录页：`frontend/src/views/login/Login.vue`
- 注册页：`frontend/src/views/login/Register.vue`
- 任务页：`frontend/src/views/task/TaskList.vue`
- 登录拦截器：`backend/src/main/java/com/example/codeleapbackend/common/AuthInterceptor.java`
- 登录接口：`backend/src/main/java/com/example/codeleapbackend/user/controller/UserController.java`
- 用户业务：`backend/src/main/java/com/example/codeleapbackend/user/service/impl/UserServiceImpl.java`
- 任务接口：`backend/src/main/java/com/example/codeleapbackend/task/controller/TaskController.java`
- 任务业务：`backend/src/main/java/com/example/codeleapbackend/task/service/TaskService.java`
- 数据库映射：`backend/src/main/java/com/example/codeleapbackend/task/mapper/TaskMapper.java`
- 任务实体：`backend/src/main/java/com/example/codeleapbackend/task/pojo/entity/Task.java`
- 后端配置：`backend/src/main/resources/application.yml`

## 九、遇到问题时的排查顺序

### 前端打不开

1. 看终端 Vite 是否启动成功。
2. 看地址和端口是否正确。
3. 看浏览器 Console。
4. 看路由文件有没有导入错误。
5. 看 Network 中静态资源是否404。

### 接口请求失败

1. 看 Network 中真实请求地址。
2. 确认请求方法。
3. 确认请求体字段名。
4. 看 HTTP 状态码。
5. 看后端控制台日志。
6. 用 Postman 单独请求后端。
7. 判断是前端问题、跨域问题、登录问题还是数据库问题。

### 后端启动失败

1. 看错误堆栈最后的根本原因。
2. 确认 JDK 17。
3. 确认 8080 端口未占用。
4. 确认 MySQL 已启动。
5. 确认数据库名、用户名和密码。
6. 确认 Maven 依赖下载完成。

### 数据库错误

1. 确认正在连接哪个数据库。
2. 执行 `SHOW TABLES`。
3. 执行 `DESC 表名`。
4. 检查字段名与 Entity。
5. 手工执行对应 SQL。
6. 再检查 MyBatis-Plus 的查询条件。
